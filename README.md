## 📌 Project Overview

Soul Foods wanted to analyze sales performance of **Pink Morsels** before and after a pricing change.

This project processes raw sales datasets, generates cleaned output, visualizes sales trends using Dash, provides region-based filtering, and validates the application with automated tests.

---

## ✨ Features

- 📊 Process multiple CSV datasets
- 🧹 Clean and transform raw sales data
- 💰 Calculate total sales
- 📅 Sort data chronologically
- 🌍 Filter sales by region
- 📈 Interactive Dash dashboard
- 🎨 Styled user interface
- ✅ Automated testing with Pytest
- ⚙️ Continuous Integration bash script

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/deoreparth700-design/quantium-python-setup.git
```

### Move into the project

```bash
cd quantium-python-setup
```

### Create a virtual environment

```bash
python -m venv venv
```

### Activate the virtual environment

**Windows**

```bash
venv\Scripts\activate
```

**macOS/Linux**

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
pip install "dash[testing]"
```

## 🔄 Continuous Integration

Run the automated test script:

```bash
bash run_tests.sh
```

The script:

- Activates the virtual environment
- Executes all tests
- Returns exit code **0** on success
- Returns exit code **1** on failure
